## 推荐项与可选项

- 范围高亮、技能说明、战斗日志、角色选择和初始站位已有基础样式。移动范围改为后端确认的合法相邻目标；攻击 / 技能颜色范围仍是距离提示，具体目标合法性由后端动作预览和执行接口判定。
- 专属 / 通用 / 奖励技能有来源标记；AP 不足、沉默、模板禁用、空技能堆叠通过后端预览禁用；用尽的技能由后端移出，前端同步。
- 默认资源到正式资源的替换流程和来源登记已补充。
- 第二层的正式角色 / 技能素材全面统一、第三层正式资源精修，以及持续灼烧、结盟连接线、立绘过渡等可选细节，保留为持续迭代任务。基础占位验收不代表这些内容已全部制作。

## 本次发现并修复的问题

1. 只有空 URL 回退，失效图片仍显示破图：统一 `GameImage` 回退。
2. 移动只有到达后缩放，缺少跨格平移：保存展示起终点，播放 320ms 平滑移动。
3. 伤害分支覆盖死亡，死亡单位先被移出地图：先显示伤害，保留死亡棋子播放淡出，再移除。
4. 当前角色光圈动画覆盖其他角色动作：高亮移到独立伪元素，只保留一层同心光圈。
5. 普通特效围绕画布原点放大、视角变化后脱离目标：围绕目标缩放并每帧重新投影。
6. Pixi 爆炸可能遮挡飘字：增加上层飘字层，随地图移动和缩放。
7. 反击伤害同时出现、奖励 / 胜利遮住死亡动画：基础行动也接入播放队列，完成后显示结算弹窗。
8. 移动范围含无法一步到达的格子，沉默 / 禁走仍给出可用提示：范围及技能可用性读取后端预览；补齐相应预览检查。
9. 结盟关系未返回前端、新召唤物图片未被映射：增加展示合同 `alliances`，读取实体自身资源。
10. 状态名称 / 图标分散、部分状态缺少映射：集中状态视觉配置，增加统一 SVG 图标。
11. 挖宝成功 / 失败缺少基础反馈，治疗没有实际数值：补齐状态差异驱动的反馈。
12. 同名上传覆盖旧图片并可能读取缓存：每次生成独立上传 URL。
13. 站位页滚轮使用被动监听却调用 `preventDefault`：改为有清理的非被动监听。
14. 音效注册表指向不存在的文件：补充项目内合成占位音效。
15. 奖励回复可能带回旧伤害和炸弹时间线：保留已完成事件记录并识别新事件，避免重复播放，也避免队列去重后丢失奖励状态更新。
16. 窄窗口下开局步骤栏被 Flex 压缩并覆盖正文：步骤栏保留实际高度，正文按剩余空间布局。
17. 最后一次击杀同时显示奖励和胜利弹窗：先完成死亡反馈与奖励选择，再显示胜利。
18. 棋子与藏宝点同格时藏宝点覆盖棋子：棋子优先显示，仍可选择该格挖宝；挖宝反馈也作用于执行角色。
